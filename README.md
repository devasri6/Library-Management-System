                                                   Library Management System

Project Overview
         A Library Management System developed using Java, MySQL, and JDBC to manage books, members, and borrowing records.

Technologies Used
- Java
- MySQL
- JDBC
- Eclipse IDE

Features
- Add Book
- Register Member
- View Books
- Update Book
- Delete Book
- Issue Book
- Return Book

      Database
The project uses three main tables:
- Books
- Members
- Borrow Records
